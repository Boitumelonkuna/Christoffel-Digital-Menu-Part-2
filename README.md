# Christoffel Digital Menu — Part 2

This project is based directly on the Part 1 design for the Christoffel Digital Menu App.

## Part 1 design carried into Part 2

- Cream background
- Dark green primary colour
- Gold accents
- White rounded cards
- Large bold headings
- Three main screens: Menu, Manage, Filter
- Bottom navigation
- Menu cards showing course, dish name, description and price
- Manage screen with dish name, description, price and Starter/Main/Dessert choices
- Guest course filter

## Part 2 functionality

- Add menu items
- Validate required fields
- Validate positive prices
- Confirm successful additions
- Display all added menu items immediately
- Remove menu items with confirmation
- Automatically update totals and average price
- Filter by All, Starters, Mains and Desserts
- Show an empty-state message when no matching dishes exist
- Shared menu state between all screens

## Run

npm install
npx expo start

Then use Expo Go or an emulator. Press `w` for the web version.
